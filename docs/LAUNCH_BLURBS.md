## LinkedIn

**Option A — problem-first (recommended)**

> If you do web dev on a Mac, you know the mess: a Vite app on 5173, a Django API on 8000,
> three Ghost sites, Docker publishing half a dozen ports — and no easy way to see what's
> what or which one is safe to kill.
>
> So I built **IO: localhost** — a small native macOS app that shows every process listening
> on a local port, grouped by app and color-coded so you don't nuke a system process by
> accident. Point it at a project folder and it detects the framework *and* your package
> manager and starts it for you (`pnpm dev`, `python3 manage.py runserver`, `ghost run`…),
> with live logs and one-click stop.
>
> It's free, open source (MIT), and runs entirely on your machine — no telemetry, no network.
>
> Grab it here 👉 https://github.com/SirArthur23/IOlocalhost
>
> Would love feedback from anyone juggling a lot of localhost servers.
>
> #macOS #WebDevelopment #DeveloperTools #Swift #SwiftUI #OpenSource
